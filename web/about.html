Azərbaycan dilində mətni səsə çevirmək — pulsuz və internetsiz

azerbaycan-tts Azərbaycan dilində yazılmış mətni nitqə çevirən açıq mənbəli modeldir. Hesablamanın hamısı sizin brauzerinizdə gedir: qeydiyyat yoxdur, server yoxdur, mətniniz heç yerə göndərilmir. Səhifə bir dəfə yükləndikdən sonra internet olmadan da işləyir.

Səsləndirməyə başla

Necə işləyir

Model 9.36 milyon parametrli VITS şəbəkəsidir və 24 kHz keyfiyyətində səs verir. Brauzerdə ONNX Runtime Web ilə işləyir: WebGPU olan brauzerdə real vaxtdan sürətli, olmayanda isə prosessorda, daha yavaş. İlk açılışda təxminən 37 MB yüklənir, sonra brauzer onu yadda saxlayır.

Oxumazdan əvvəl mətn danışıq dilinə çevrilir: «II Dünya müharibəsi» — «İkinci Dünya müharibəsi», «25%» — «iyirmi beş faiz», «01/09/1939» — «bir sentyabr min doqquz yüz otuz doqquzuncu il», «19,99 AZN» — «on doqquz manat doxsan doqquz qəpik». Uzun mətn təxminən 15 sözlük hissələrə bölünür, çünki uzun cümlədə intonasiya düzləşir. Hərfləri fonemlərə eSpeak NG çevirir; onun WebAssembly versiyası da brauzerdə işləyir.

Məhdudiyyətlər

  • Bir səs var; emosiya idarəsi və səs klonlama yoxdur.
  • Nitq aydındır, lakin tam təbii deyil: bəzi cümlələrdə metal tembr eşidilir.
  • Latın əlifbası ilə yazılmış mətn üçündür: başqa əlifbadakı hərflər düzgün oxunmur.
  • Bir dəfəyə ən çoxu 500 simvol səsləndirilir.
  • Telefonda və WebGPU olmayan brauzerdə yavaşdır: bir cümlə bir dəqiqəyə qədər çəkə bilər.
  • Söyüşlər bip səsi ilə əvəz olunur.

Tez-tez verilən suallar

Azərbaycan dilində mətni necə səsləndirə bilərəm?

Səsləndirmə səhifəsini açın, mətni yazın və «Səsləndir» düyməsini basın. Səsi oradaca dinləyə və «Endir» düyməsi ilə WAV faylı kimi saxlaya bilərsiniz. Heç nə quraşdırmaq lazım deyil.

Pulsuzdurmu? Qeydiyyat lazımdırmı?

Pulsuzdur və qeydiyyat tələb etmir. Yeganə limit bir dəfəyə 500 simvoldur; daha uzun mətni hissə-hissə səsləndirin.

İnternetsiz işləyirmi?

Bəli. İlk açılışda model (təxminən 37 MB) yüklənir və brauzerdə saxlanılır. Bundan sonra səhifə internet olmadan da səs yaradır.

Yazdığım mətn serverə göndərilirmi?

Xeyr. Mətn və hazır səs cihazınızdan çıxmır, çünki model brauzerin içində işləyir. Şəbəkədən yalnız səhifənin, modelin və fonemləşdiricinin faylları yüklənir.

Hansı brauzerdə ən sürətli işləyir? Telefonda işləyirmi?

Ən sürətlisi kompüterdə Chrome və ya Edge-dir: orada model WebGPU ilə real vaxtdan sürətli işləyir. Telefonda da işləyir, amma hesablama prosessorda getdiyi üçün daha yavaşdır.

Kommersiya məqsədilə istifadə etmək olarmı?

Bəli: kod və model çəkiləri Apache-2.0 lisenziyalıdır, işlətmək məhdudlaşdırılmır. Yalnız bir şərt var və o, modeldən yox, fonemləşdiricidən gəlir: eSpeak NG və Python tərəfdəki phonemizer GPL-3.0-or-later lisenziyalıdır. Onlarla birləşmiş məhsulu yaymaq — masaüstü tətbiq, konteyner, müştəriyə verilən binar — GPL-3.0 öhdəlikləri gətirir. Çıxış yolu budur: model öncədən fonemləşdirilmiş mətni qəbul edir (accepts_prephonemized_input), ona görə məhsul öz fonemləşdiricisini işlədə bilər. Azərbaycanca təlim datası müəllifinin icazəsi ilə, adının çəkilməsi şərti ilə istifadə olunub. İngilis səsi sintetikdir və Apache-2.0-dır, lakin açıq-çəkidir, açıq-data deyil. Real bir insanı təqlid etmək və aldadıcı məzmun hazırlamaq qadağandır. Bu, hüquqi məsləhət deyil.

Modeli öz kompüterimdə necə işlədə bilərəm?

Kod GitHub-dadır: repozitoriyanı klonlayın, pip install -r requirements.txt edin və python say.py "Salam." işə salın. Model adi noutbuk prosessorunda real vaxtdan 2-4 dəfə sürətli işləyir və internet tələb etmir. Çəkilər Hugging Face-də də var, PyTorch və ONNX formatında.

Model necə hazırlanıb?

Model Owen Song-un ingilis dilli Inflect-Micro-v2 modelindən (Apache-2.0) uyğunlaşdırılıb: 25.07 saatlıq Azərbaycan nitqi üzərində 200 000 addım öyrədilib. Təlim datası ughurabbasov/azerbaijani-tts-dataset-dir; müəllifi istifadəyə icazə verib və adının çəkilməsini xahiş edib. Səhifədəki ingilis səsi isə baza modelin özüdür: modelin haradan başladığını eşitmək üçün.
