Avaz — text-to-speech that runs on your device

Avaz is open-source text-to-speech that runs on the device itself — in the browser, on a CPU, with no server. We are building it for natural intonation on phones. Today it speaks Azerbaijani and English. There is no sign-up, your text is never sent anywhere, and once the page has loaded it works with the network switched off.

Start speaking

Our goal

A voice that runs on the phone itself and reads with natural intonation: no server, no account, no connection needed, and the text stays on the device. That is where we are heading.

Everything we make on the way is open source. The code and the model weights are Apache-2.0 and the training pipeline is public, so anyone can check them, run them and build on them.

Languages

  • Azerbaijani — the main voice, the Inflect-Micro-v2 Azerbaijani model. It reads numbers, dates, money and abbreviations the way a person says them aloud.
  • English — the base model the Azerbaijani one was adapted from, owensong/Inflect-Micro-v2 by Owen Song, unmodified, so you can hear where the Azerbaijani voice started.
  • Turkish and Russian — next. They are planned; there are no dates yet.

Where we are

We are not there yet. The current 9.36M-parameter model is small and fast, but its intonation is still flat, especially over long sentences, and phone browsers run it slowly. We list our weak spots openly and fix them release by release.

  • Intonation flattens over long sentences. For now the text is cut into chunks of about 15 words, a length chosen by testing. That softens the problem; it does not remove it.
  • The reading is flat. eSpeak NG, which turns the letters into phonemes, puts a stress on 92.2% of words, so few of them stand out. The command line has an experimental stress layer (--prosody); it does not improve every text, so it stays optional.
  • Some sentences carry a metallic resonance. It comes from the vocoder, the part of the model that makes the sound. A cleanup tool in the repository reduces it in saved audio; the playground does not apply it.
  • It is slow in a phone browser. There the model usually runs on the processor (WebAssembly, with an int8 decoder), and one sentence can take up to a minute. On a computer with WebGPU it is faster than real time. Speed on phones is our main work, together with intonation.
  • One voice. There is no emotion control and no voice cloning.
  • The training audio is most likely synthetic. It was probably made by another TTS system, so this voice cannot sound better than that system. A better voice needs better recordings.

Smaller limits: at most 500 characters are spoken at a time; the text should be in the Latin alphabet, because letters from other scripts are not read correctly; profanity is replaced with a bleep.

How it works

The model is a 9.36-million-parameter VITS network that produces 24 kHz audio. It runs in the browser through ONNX Runtime Web: faster than real time where the browser has WebGPU, and on the processor, more slowly, where it does not. The first visit downloads about 37 MB; after that the browser keeps it.

Before it is read, the text is turned into words as they are spoken: «II Dünya müharibəsi» becomes «İkinci Dünya müharibəsi», «25%» becomes «iyirmi beş faiz», «01/09/1939» becomes «bir sentyabr min doqquz yüz otuz doqquzuncu il», and «19,99 AZN» becomes «on doqquz manat doxsan doqquz qəpik». Long text is cut into chunks of about 15 words, because intonation flattens over a long sentence. eSpeak NG turns the letters into phonemes, and its WebAssembly build runs in the browser too.

Frequently asked questions

What is Avaz?

Avaz is open-source text-to-speech that runs on the device itself: in the browser, on a CPU, with no server. We are building it for natural intonation on phones. Open the playground, type the text and have it spoken: you can listen right there and save the audio as a WAV file. Nothing needs to be installed.

Which languages does it speak?

Azerbaijani and English today. The Azerbaijani voice is our own model, Inflect-Micro-v2 Azerbaijani; the English one is the base model it was adapted from, owensong/Inflect-Micro-v2 by Owen Song, unmodified. Turkish and Russian are next: they are planned, but there are no dates yet.

Is it free? Do I need an account?

It is free and needs no account. The only limit is 500 characters at a time; speak longer text in parts.

Does it work offline? Is my text sent anywhere?

It works offline, and your text is not sent anywhere. The first visit downloads the model (about 37 MB) and the browser keeps it; after that the page makes speech without the internet. The text and the audio never leave your device, because the model runs inside the browser. The network is used only to download the files of the page, the model and the phonemiser.

Does it work on a phone?

It works, but slowly. In a phone browser the model usually runs on the processor (WebAssembly, with an int8 decoder), and one sentence can take up to a minute. Chrome or Edge on a computer is fastest: there the model runs on the GPU through WebGPU, faster than real time. Speed on phones and natural intonation are our main work.

Can I use it commercially?

Yes: the code and the model weights are Apache-2.0, and running them is unrestricted. There is one condition, and it comes from the phonemiser, not the model: eSpeak NG, and phonemizer on the Python side, are GPL-3.0-or-later. Redistributing a combined work — a desktop app, a container image, a binary handed to customers — brings GPL-3.0 obligations. The way out: the model accepts pre-phonemised input (accepts_prephonemized_input), so a product can use its own phonemiser. The Azerbaijani training data is used with its author's permission, on condition of attribution. The English voice is synthetic and Apache-2.0, but the release is open-weight, not open-data. Impersonating a real person or producing deceptive content is not permitted. This is not legal advice.

How do I run the model on my own computer?

The code is on GitHub: clone the repository, run pip install -r requirements.txt and then python say.py "Salam.". On an ordinary laptop processor the model runs 2-4x faster than real time and needs no internet. The weights are also on Hugging Face, in PyTorch and ONNX.

How was the model made?

The Azerbaijani model, Inflect-Micro-v2 Azerbaijani, was adapted from Owen Song's English Inflect-Micro-v2 model (Apache-2.0): 200,000 training steps on 25.07 hours of Azerbaijani speech. The training data is ughurabbasov/azerbaijani-tts-dataset; its author permits use and asks to be credited. The English voice on the page is the base model itself, so you can hear where the Azerbaijani one started.
